# Desktop Configuration

[catalog.json](catalog.json) is independent of the distribution base system. Draft GNOME/KDE combinations check package availability in the target repositories at execution time; DDE is enabled only for explicit Deepin base inputs and does not add DDE PPAs or mixed repositories to Debian/Ubuntu.

The default requested scale is 200%, which can be overridden with the assembler's `--scale-percent` flag. GNOME uses the integer toolkit default and KDE uses the Qt default; this is a lightweight initial setting and does not replace per-output Wayland layout confirmation on unknown displays. The DDE configuration interface is not yet confirmed, so 200% is recorded only as an initial setup target without faking an applied state.

GNOME uses the built-in Shell on-screen keyboard and does not install Caribou. Plasma configures Maliit only when the target repository provides it and the corresponding desktop entry exists, and it requires Wayland. The DDE on-screen keyboard is unconfirmed, so no dummy service is created. Screen rotation depends on hardware sensors; installing `iio-sensor-proxy` does not imply the device already supports auto-rotation.

GNOME UI animations are enabled by default. Both the full stager and the multi-distro assembler write the same `gnome/defaults.ini` to local dconf, and the release builder compiles the database after staging, overriding the reference image's animations-off default without locking user preferences. GNOME Shell still temporarily disables animations under software rendering or remote sessions requesting reduced motion; no forced environment variables are used to mask GPU issues. Night Light depends on DRM gamma LUT, while SM8750 currently only exposes CTM/PCC, so forcing it on via `gsettings` will not make it work.

References: [GNOME On-Screen Keyboard](https://help.gnome.org/gnome-help/keyboard-osk.html), [Ubuntu noble Plasma packages](https://packages.ubuntu.com/search?keywords=plasma&searchon=names&suite=noble), [Ubuntu noble Maliit](https://packages.ubuntu.com/noble/maliit-keyboard), [Debian trixie Maliit](https://packages.debian.org/trixie/arm64/maliit-keyboard), [Arch Linux ARM GNOME](https://archlinuxarm.org/packages/aarch64/gnome-shell), [Arch Linux ARM Plasma](https://archlinuxarm.org/packages/aarch64/plasma-desktop).
